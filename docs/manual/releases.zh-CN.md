# 发布版本

发布说明统一从这里进入，不再把每个版本平铺到全局文档侧边栏。最新版本保持突出，历史版本永久可访问，并按 Minor 系列分组归档。

## 最新版本

- [v0.6](v0.6/) — Parallel-first Agent 执行、Task-ready 仓库上下文、标准化 LSP 语义与有界项目命令的精确授权。

## 0.6.x

- [v0.6](v0.6/) — 并行执行契约、更强仓库理解，并在不削弱硬安全边界的前提下降低命令阻力。

## 0.5.x

- [v0.5.2](v0.5.2/) — MCP 易用性、并行执行指引、Setup/Update 生命周期、授权与验证治理。
- [v0.5.1](v0.5.1/) — 资源治理、子进程清理、语义稳定性与移动端 WebUI 优化。
- [v0.5.0](v0.5.0/) — Hardened Semantic Provider、Warm LSP Session 与 Semantic Navigation。

## 0.4.x

- [v0.4.3](v0.4.3/) — Agent 主机安全配置、稳定 OAuth 会话、统一 MCP 传输与授权体验。
- [v0.4.2](v0.4.2/) — 后台并发隧道、Tailscale Funnel、链接推送与优雅退出。
- [v0.4.1](v0.4.1/) — Tunnel 提取和 Agent Context Budget 修复，以及文档扩充。
- [v0.4.0](v0.4.0/) — Agent Context、Architecture-first 可观测性与有界开发自动化。

## 0.3.x

- [v0.3.0](v0.3.0/) — 历史 0.3 产品形态与主要变化。

## 发布策略

每个 Release Page 都是不可变的历史文档。以后发布新版本，只需要新增中英文版本页，并在本索引顶部增加一条；全局侧边栏始终只保留一个“发布版本”入口，因此版本再多也不会让主导航持续膨胀。
