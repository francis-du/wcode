# wcode v0.4.1

v0.4.1 is a maintenance release on top of the 0.4 agent-context and observability foundation. It fixes two behavioral bugs — tunnel URL extraction and the `agent_context` token budget — and ships a substantially expanded documentation set: a vendor-by-vendor MCP client matrix, refreshed product screenshots, and redesigned documentation pages.

## Tunnel URL extraction

- Provider web hosts such as `admin.localhost.run`, `www.localhost.run`, and `api.trycloudflare.com` are no longer mistaken for tunnel URLs when parsing provider output.
- `localhost.run` SSH tunnels are now recognized on the `.lhr.life` domain as well as `.localhost.run`.
- Quick-tunnel host matching is case-insensitive and tolerates trailing dots, so provider output with uppercase domains no longer fails provider selection in `auto` mode.
- The monitor's quick-tunnel check now shares a single implementation with the tunnel runtime (`crate::tunnel::is_quick_tunnel_url`) instead of maintaining a second suffix list.

## Agent Context budget

- `agent_context` now enforces its bounded token budget instead of only targeting it, so an oversized pack cannot leak past the limit on ambiguous or cross-module tasks.

## Documentation

- The integration guide gained a vendor-by-vendor client matrix covering stdio, custom remote URL, and OAuth support across international and Chinese chat and cloud clients — including WorkBuddy, Doubao Work, and Trae Work — with concrete registration steps for verified hosts.
- Product screenshots were replaced with current captures under descriptive names, including a full-page Project Observatory shot.
- Documentation pages were redesigned for readability: a tighter content column, calmer headings, compact code blocks, and lighter tables.

## Upgrade

```bash
curl -fsSL https://raw.githubusercontent.com/francis-du/wcode/main/install.sh | sh
```

No Design State, Workspace, or authorization migrations are required; `wcode restart` is enough after replacing the binary.
