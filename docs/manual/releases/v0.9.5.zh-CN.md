# wcode v0.9.5

本版移除支撑模型代码视图的有界图谱搜索与差异路径中剩余的、可避免的分配。

| 变更 | 用户可见行为 |
| --- | --- |
| 搜索关系计数 | 代码图谱搜索按节点统计 incident 边时借用端点文本，不再在每次查询时把每条边的两个端点字符串克隆进映射。 |
| 差异边排序 | 对端点相同的边做排序时，tiebreaker 比较零分配的类型名，而不是每次比较都格式化两个类型。排序结果不变。 |

两处都只改变实现方式。搜索排序、匹配类型、差异分组与截断均不变，类型排序的等价性由测试固定。

## 升级与重连

使用带版本的[发布下载](https://github.com/francis-du/wcode/releases/tag/v0.9.5)与对应 SHA256SUMS 做固定版本升级。现有 `wcode update` 命令会选取最新稳定版，没有 `--version` 选项。

替换安装后，请在检查完进行中的工作之后重连 MCP Host 或安排服务重启。源码发布不会替换已在运行的进程。请检查新启动可执行文件的版本与其配置路径。

## 验证身份

发布工作流记录确切提交，运行三平台测试与独立源码包检查、依赖审计、Design/可追溯性检查、真实 WebKit 矩阵以及全部 300 个不同对抗轮次。发布另外构建平台归档并校验全新下载。GitHub release 链接指向真实完成的运行；较早的绿色候选不能验证较新的提交。

WTeam 部署、数据库迁移、身份配置与已安装服务的升级有各自的验收步骤。

## 命令发现与有界执行

使用 `wcode help-all`、`wcode help-all setup` 与 `wcode help-all --json` 在不启动运行时的情况下检查命令目录。使用 `agent_context` 开始编码；`balanced`、`fast` 与 `light` 预设保留其执行与授权边界。被动检查使用 `--read-only --no-exec --no-semantic`。

命令策略与授权默认宽松。`--no-exec` 覆盖会话命令授权，显式硬化开关在安全参考中说明，而不是由默认值暗示。

对于被打断或不完整的检查，请保留 `timed_out`、`output_incomplete` 与原始任务 ID，并在请求另一次执行之前先读取其结果。维护者门禁包括 `cargo test --locked`、`cargo clippy --locked --all-targets -- -D warnings` 与当前的在线审计。JavaScript 回归使用 Node 24。
