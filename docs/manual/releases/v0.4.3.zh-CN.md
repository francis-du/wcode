# wcode v0.4.3

v0.4.3 主要解决三件事：接入更省事，授权边界更清楚，运行时状态更容易看懂。本版加入项目内 Agent 主机配置，把三种 MCP 传输方式收回同一条运行链路；隧道重连时 OAuth 会话不会因为域名变化而失效，TUI 和 WebUI 也能直接看到当前项目的真实状态。

## Agent 配置

- `wcode --workspace "$PWD" agent-plugin --install-all --dry-run` 只报告本机识别到的主机、判断依据、目标文件、预计合并方式和手工步骤，不会写文件。
- `--install-all` 只处理已经确认格式的项目内 JSON 或 TOML。已有 MCP Server 会保留；写入带 SHA 校验并保持原子性；无法确认的 Schema 直接停止自动修改。
- Claude Code、Codex、VS Code + GitHub Copilot、Cursor、Gemini CLI、Qwen Code、Kiro、Qoder CLI 和 OpenCode 在格式可靠时使用专用 Adapter；没有稳定项目内格式的主机只给出明确手工说明。
- `wcode-agent-plugin/` 现在是 README、Skill、Manifest 和 Agent Plugins 1.0 `mcp.json` 的唯一来源。导出支持纯 Skill、本地 stdio 和远程 Streamable HTTP，配置里不放凭据。

## MCP 会话与隧道

- 本地 stdio、首选远程 `/mcp` Streamable HTTP，以及兼容旧客户端的 `/sse` + `/message`，共用 JSON-RPC Dispatch、Harness、Workspace Policy 和 Tool Catalog。
- SSE 对 Session 数量和 Channel 容量设上限，客户端断开后会清理；每个 Session 都绑定 OAuth Client 和当前隧道 Origin，Origin 防护仍然生效。
- Client 注册以及 Access / Refresh Token 不再按时间失效，重启后也会恢复。状态按配置的 Workspace 根目录隔离；已经验证的新隧道可以接续原会话，Resource Binding 不会因此放宽。
- OAuth Metadata 和验证页面按收到请求的已登记隧道生成。用户从哪条隧道进入，就会在那条隧道的域名完成验证。
- v0.4.3 之前签发的 Client ID 可在下一次完成授权时恢复，Redirect 校验和本机配对码仍然保留。

## Workspace 授权

- WebUI 可以把当前父 Workspace 内的目录登记为受控 Subspace。相对路径从当前选中的 Workspace 解析；Symlink Escape 和普通重叠 Workspace 限制继续阻断。
- “可执行程序访问”和“精确仓库操作”仍是两层授权。WebUI 批准只对当前 Workspace 生效；拒绝不会留下 Grant；参数变化后必须重新批准精确操作。
- 自动发现会识别常见 Rust、JavaScript、Python、Go、Java、Gradle 和 Swift 项目边界，也不会在一个已经识别的项目中继续无限拆分嵌套 Crate。

## 操作界面

- 按 `I` 读取当前项目的 Software Intelligence，按 `C` 查看完整命令清单。OAuth 和 MCP 已连接后，配对码仍会留在页头。
- TUI 使用与文档一致的主题色，项目与帮助链接固定在 Footer；可执行程序授权和精确操作授权分开展示。
- Project Observatory 新增受限文件树、目录深度、大文件列表和 1,000 行上限提示。索引达到边界时会明确显示“已截断”。

## 仓库结构

- 过长的 Rust、JavaScript、CSS 和测试文件已经按领域拆进子目录。测试仍统一放在根 `tests/`；文件名受限；维护中的文本文件最多 1,000 个物理行。
- `.wcode` Design State 已同步这些结构约束，以及新的 Agent、Transport、Authorization、TUI 和 WebUI 契约。
- 搜索实现复用 ASCII 大小写无关匹配与多查询 Finder，同时保留重叠 Pattern 的正确结果。

## 升级

```bash
curl -fsSL https://raw.githubusercontent.com/francis-du/wcode/main/install.sh | sh
```

无需迁移 Workspace 或 Design State。替换二进制后执行 `wcode restart`。旧版 Client 可能需要再完成一次授权，让 wcode 恢复并保存原 Client ID；此后的重启会继续保留会话。
