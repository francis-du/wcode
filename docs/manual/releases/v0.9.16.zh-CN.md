# wcode v0.9.16

- **Kimi Code CLI 安装：**全局安装预览显示可执行文件的绝对路径，项目安装写入可移植的 stdio 条目。保留已有选项，已禁用或远程条目不改写。可初始化空配置，不覆盖有内容但格式错误的 JSON。
- **Git 工作树：**状态快照识别 `.git` 文件，并保留中文路径和文件名中的箭头。观测台复用同一套 Git 路径解析，避免漏掉连续编辑。
- **变更审查：**将行数统计归到实际路径；审查不完整时不声称工作树干净或仅存在文档变更。

安装后运行 `wcode setup --global` 并确认计划。新开 Kimi 会话，先用 `/mcp` 检查连接，再请求只读 `workspace_info` 调用。成功发现服务不代表工具一定已提供给模型。

用 `wcode help-all`、`wcode help-all setup` 和 `wcode help-all --json` 查看命令目录，无需启动运行时。用 `agent_context` 开始仓库工作。`balanced`、`fast`、`light` 不改变授权；只读检查可使用 `--read-only --no-exec --no-semantic`。命令中断时，保留 `timed_out`、`output_incomplete` 和任务 ID，再决定是否重试。

发布门禁包括 `cargo test --locked`、`cargo clippy --locked --all-targets -- -D warnings`、Node 24 回归和各平台检查。正式发布后请使用对应的[发布下载](https://github.com/francis-du/wcode/releases/tag/v0.9.16)与校验和。
