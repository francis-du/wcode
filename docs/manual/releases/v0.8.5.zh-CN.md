# wcode v0.8.5

v0.8.5 在 Observatory 中串联真实代码变更、源码导航、影响与匹配版本的证据，同时改进代码到测试的上下文检索，展示实测 Engineering Fitness，并修复交互和验证历史的边界问题。

## 代码与变更审查

- 通过有界、只读的源码和差异视图查看暂存、未暂存、组合、未跟踪和已删除的变更。
- 将源码、差异和影响响应绑定到选中的 Workspace、快照及源码 SHA。并发修改、过期响应、脱敏内容和矛盾映射明确显示为不可用或部分可用。
- 从组件下钻到文件和符号。语义关系必须具有合法的 Provider 位置、位置编码、范围和响应形状；文本候选不会被展示为语义调用边。
- 在变更旁展示匹配的验证证据。结果计数、计划总数、状态或版本互相矛盾时，不再声称具有当前证据或匹配风险。

行为与精度契约详见[变更审查](../../change-inspection/)。

## 上下文检索与 Fitness

- 对相关代码到测试候选排序，不再将无关测试预填到结果中。宏和命名匹配保留明确的文本来源与源码校验。
- 为每个文件和目标保留有界代表行，避免高频文件耗尽全部搜索额度。公共搜索顺序与分页保持不变。
- 识别 JSX/TSX 的 test 和 spec 路径，保留最多八个精确测试目标，并在补充扫描达到上限时明确标注部分覆盖。
- 分开展示基准观测和运行结果，保留原始分母、p50/p95、版本身份，以及缺失、部分覆盖或历史状态。
- Fitness 使用有界的合成检索案例和选定的运行里程碑，不证明模型补丁成功率、隐藏留出集性能或整体发布就绪状态。

## 验证与交互可靠性

- 从持久历史中找到最新的匹配验证计划，包括超出展示窗口的历史。
- Execution 的验证下限提高后重新绑定计划，保留已满足要求的计划，在缺少足够证据时继续阻塞。
- 恢复命令面板启动，以及刷新失败后的增量重试。
- 隔离输入法组合键、Escape、重复快捷键、Tab 导航和焦点恢复。隐藏的项目搜索结果不能被激活，也不会因后台刷新重新弹出。
- 无障碍选中状态与刷新结果保持一致；访问面板的延迟聚焦不会从已关闭面板或命令面板抢走焦点。
- 同步中英文指引、界面文案、最小说明字号和终端品牌色。

## 兼容性与命令发现

编码任务从 `agent_context` 开始；命令超时保留 `timed_out` 和 `output_incomplete` 诊断，不会误报成功。`balanced`、`fast`、`light` 预设保持既有边界。被动检查可使用 `--read-only --no-exec --no-semantic`。

使用 `wcode help-all`、`wcode help-all setup` 或 `wcode help-all --json` 发现命令，不启动运行时。开发与 CI 使用 Node 24 运行行为检查，使用 `cargo test --locked` 运行完整测试，使用 `cargo clippy --locked --all-targets -- -D warnings` 检查代码质量。

## 验证与分发

发布门禁覆盖格式、锁定依赖检查、完整 Rust 与 JavaScript 行为测试、严格 Clippy、Release 构建、Design/Traceability、双语文档及包版本一致性。真实 WebKit 覆盖不同语言、主题、视图和屏幕宽度下的 240 个场景。在打标签前，干净工作区的 300 轮对抗工作流针对精确的发布准备提交运行。

标签发布生成 Linux x86_64、Windows x86_64，以及 macOS Apple Silicon、Intel、Universal 归档和 SHA256 校验和。分发二进制必须通过版本和帮助冒烟测试；macOS 产物在最终打包后签名并校验，安装器先暂存和验证二进制，再替换已有安装。
