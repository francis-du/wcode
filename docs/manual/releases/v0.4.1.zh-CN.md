# wcode v0.4.1

v0.4.1 是在 0.4 的 Agent Context 与可观测性基础上的维护版本。它修复了两个行为问题——隧道 URL 提取和 `agent_context` token 预算——并带来大幅扩充的文档：逐厂商的 MCP 客户端矩阵、全新产品截图，以及重新设计的文档页面。

## 隧道 URL 提取

- 解析 provider 输出时，`admin.localhost.run`、`www.localhost.run`、`api.trycloudflare.com` 这类官网域名不再被误判为隧道地址。
- `localhost.run` SSH 隧道现在同时识别 `.lhr.life` 和 `.localhost.run` 两个域名。
- 快速隧道主机匹配改为大小写不敏感并容忍末尾点号，provider 输出包含大写域名时 `auto` 模式不再误判 provider 不可用。
- TUI 的快速隧道判断与隧道运行时共用同一实现（`crate::tunnel::is_quick_tunnel_url`），不再维护第二份后缀列表。

## Agent Context 预算

- `agent_context` 现在强制执行有界 token 预算，而不仅是目标值——模糊或跨模块任务不会再让超大的上下文包越过限制。

## 文档

- 集成指南新增逐厂商客户端矩阵：覆盖国际与国内聊天和云端客户端的 stdio、自定义远程 URL、OAuth 支持情况——包括 WorkBuddy、豆包 Work、TRAE Work——并为已验证的客户端给出具体注册步骤。
- 产品截图全面换新并改用语义化文件名，包括一张 Project Observatory 整页长图。
- 文档页面为可读性重新设计：更紧凑的内容列、更克制的标题层级、更紧凑的代码块和更轻量的表格。

## 升级

```bash
curl -fsSL https://raw.githubusercontent.com/francis-du/wcode/main/install.sh | sh
```

不涉及 Design State、Workspace 或授权迁移；替换二进制后 `wcode restart` 即可。
