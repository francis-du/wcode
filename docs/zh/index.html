01 · 快速开始

一个命令，连接本地仓库。

默认会启动本地服务器、Cloudflare HTTPS 临时隧道、OAuth、终端监控和统一 Setup Hub。无需为不同 AI 平台输入不同的启动参数。

1

安装

curl -fsSL https://raw.githubusercontent.com/francis-du/wcode/main/install.sh | sh

适用于 macOS 与 Linux；Windows 可使用仓库中的 PowerShell 安装脚本。

2

暴露工作区

wcode -w "$PWD"

默认监听 127.0.0.1:8765。可以通过 -H/--host、-p/--port 修改，并用 -j/--max-parallel-tools 调整并行度。

3

连接 AI

https://…trycloudflare.com/mcp

在 Setup Hub 选择平台，粘贴同一个 /mcp 地址，选择 OAuth，再输入终端显示的六位验证码。

Grok 默认支持

正常启动 wcode，在自动打开的 Setup Hub 选择 Grok，使用共享 MCP 地址和 OAuth 配对码。

wcode -w "$PWD"
Claude 默认支持

同一个 Setup Hub 会打开 Claude 自定义连接器页面，不需要 Claude 专用命令。

wcode -w "$PWD"
Mistral 默认支持

选择 Mistral 即可；服务器、OAuth 流程与工具集合在所有平台保持一致。

wcode -w "$PWD"
其他标准 Remote MCP 客户端

复制终端中的 /mcp 地址。支持 OAuth Discovery、PKCE 与 DCR 的客户端可自动完成认证。

wcode -w "$PWD"
02 · 平台兼容性

一个服务器，多种 AI 界面。

信息核对日期：2026 年 8 月 23 日。每张卡片分别说明协议支持、免费方案、付费方案、实际消耗的额度与官方证据。wcode 不绕过任何订阅、Credits、Token、消息、速率或 BYOK 计费规则。

“传输支持”不等于“已验证原生 OAuth”。部分平台支持 Streamable HTTP，但尚未公开说明自动 OAuth Discovery；wcode 不会为了显示兼容而降级默认认证。

01

协议双栈

支持 MCP 2026 无状态请求，同时保留 2024/2025 initialize 路径，避免客户端必须同时升级。

02

标准 OAuth

客户端从 401 Bearer Challenge 发现元数据，通过 PKCE 与 DCR 完成浏览器授权。

03

有界并行

全局信号量反映真实任务；可通过 -j 调整上限，独立读取可并行，依赖编辑保持顺序。

04

精确上下文

优先使用符号、项目上下文和批量检索，减少无意义整文件输入。

04 · 连接流程

OAuth 是 MCP 体验的一部分。

无需把长期 API Key 粘贴到任意第三方客户端。兼容客户端可直接从受保护的 MCP 地址发现授权服务器。

AI 客户端wcode /mcpwcode OAuth浏览器
1 · 发现POST /mcp401 + resource_metadata
2 · 元数据/.well-known/…
3 · 注册POST /register · DCR
4 · 授权/authorize + PKCE六位验证码
5 · TokenPOST /token
6 · 使用工具Bearer + POST /mcptools/list · tools/call
为什么仍支持 DCR？

新版 MCP 更偏向 Client ID Metadata Document，但保留 DCR 兼容路径。wcode 默认不抓取任意客户端提供的元数据 URL，以免新增 SSRF 和出站网络信任边界。

05 · 安全模型

权限本身就是产品能力。

模型不会继承整台电脑。路径、写入、命令、OAuth Token 和并发任务都经过明确边界。

⌂

工作区隔离

模型只能看到 --workspace 指定的根目录；绝对路径、父级穿越、符号链接别名、过宽根目录和凭据路径默认拒绝。

↻

防止陈旧写入

编辑依赖精确文本和 SHA-256 前置条件，写入原子化、有大小限制，并保留权限。

⌘

默认不使用 Shell

命令以参数数组执行。仓库控制的高风险构建、脚本和解释器需要显式信任。

◉

OAuth + 配对

PKCE 保护授权码；重定向地址受限；访问 Token 绑定资源；刷新 Token 轮换。

◎

Origin 校验

请求包含 Origin 时必须匹配配置的公网 MCP Origin，降低 DNS Rebinding 风险。

≋

真实可观测

TUI 显示真实排队、运行、完成、失败和槽位占用，不模拟 Agent 活动。

06 · 用户文档

默认简单，配置仍然完整。

普通用户使用一个命令；网络、端口、并行度、隧道、写入、执行和安全选项仍保留。

CLI 参数

wcode -w "$PWD"
-w, --workspace <PATH>

暴露代码根目录；可重复指定。

-H, --host <HOST>

本地监听地址，默认 127.0.0.1。

-p, --port <PORT>

本地监听端口，默认 8765。

-j, --max-parallel-tools <N>

全局子任务并行度上限。

--public-url https://…

使用稳定公网反向代理代替临时隧道。

--no-tunnel

仅本地运行，不启动公网隧道。

--read-only

禁用文件修改工具。

--no-exec

禁用命令执行。

--no-open

启动后不自动打开 Setup Hub。

--no-monitor

关闭终端实时监控。

常见问题

为什么需要公网 URL？

Grok、Claude 等云端 AI 从平台服务器发起连接，无法访问你的 localhost。wcode 默认创建临时 HTTPS 隧道，也支持 --public-url。

隧道会绕过认证吗？

不会。隧道只提供可达性；MCP 端点仍需要 OAuth。

wcode 会绕过平台额度或订阅吗？

不会。模型调用仍受平台订阅、Credits、Token、消息、速率或 BYOK 账单约束。

为什么不是所有平台都显示原生支持？

部分平台仅公开了 Remote HTTP/SSE 传输支持，没有说明 OAuth Discovery。wcode 不会静默降级认证。
